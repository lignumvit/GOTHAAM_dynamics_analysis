# GOTHAAM_dynamics_analysis
A quick and dirty repo for analysis to be shared with GOTHAAMites

## Python Environment

A Conda environment titled "gothaam\_ana" can be created by running

	conda env create -f env/environment.yml

Once this envirnment is installed, it can be activated by running

	conda activate gothaam_ana

## Running the Jupyter Notebook

Once the gothaam\_ana Conda envrironment is created and activated, open the Jupyter
notebook by running the following command in the top of this repository:

	jupyter-notebook

This command should open a tab in your browser where you can double click on the provided
notebook ("gothaam\_bl\_ana.ipynb") to open it. Then you can run the notebook or cells
as desired.

## Interactive HTML

For convenience, the notebook is provided in html form as well ("gothaam\_bl\_ana.html"), 
allowing users to simply
download the html and open in a browser of choice to view and interact with the figures
in the notebook.
